**<h1>Features</h1>**
- Home Page
  
![image](https://github.com/user-attachments/assets/3f048eb9-e361-42fd-8257-47f1149d7ba7)
- Questions for quiz are fetched from database and shuffled. Hence, each time user get unique order.

![image](https://github.com/user-attachments/assets/5b7d120f-90fe-4537-8c01-e2063f39a377)

![image](https://github.com/user-attachments/assets/5a19b4b3-c4a2-4ade-9561-60d6207f316b)


- Order of options for quiz questions are shuffled for every quiz. It helps to prevent from mal practice.
- When quiz is submitted, opted answers are validated with correct answers present in database. Then, score along with opted answers and its correct answers are shown.

  ![image](https://github.com/user-attachments/assets/16664e4d-49f6-40cf-85c5-98dd2833ff9a)
- Validating with correct answer happens in the backend environment.Such that no where in the develpoers tools correct answer is present while attempting the quiz.

  ![image](https://github.com/user-attachments/assets/03059d17-1126-4f93-8b53-9756463d5fea)
- Results are stored in the database with name and date.

![image](https://github.com/user-attachments/assets/fbee0d30-7dda-4484-a5d9-d55372135437)


**<h1>Technology used</h1>**
- React Js - Context API for state management , Router for navigation
- Node JS and Express Js for backend development
- MongoDB Database
- AWS Deployment

**<h1>Scope of development</h1>**
- Timer can be added while attempting quiz.
- Quiz should be ended when other tab is opened or minimized.
- Download Results report when quiz is submitted
- Different colours for questions numbers div as per question status (Attempted, Unattempted, Not visited)
